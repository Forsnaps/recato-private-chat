Conversa privada do Recato: como confirmar

Na conversa privada, o que escreves é cifrado no teu telemóvel ou no teu browser e só é lido dentro de uma caixa-forte verificada. O servidor do Recato só passa bytes cifrados. As conversas guardadas ficam cifradas com uma chave que só tu tens.

Tudo isto depende de o código do ecrã ser o publicado. Na app e na extensão, esse código vem instalado com elas. Nesta página, vem do servidor do Recato em cada visita. Por isso há três formas de o confirmar.

1. Na app Android

O ecrã da conversa privada vem dentro da app e só muda com uma versão nova na loja. Os ficheiros dele estão na app em assets/privada/ e têm as impressões digitais publicadas.

2. Com a extensão «Recato — Conversa privada»

No Chrome, no Edge e no Firefox, a conversa privada abre a partir da cópia do ecrã que vem dentro da extensão: o código não vem do servidor. E se abrires esta página com a extensão, ela confere-a: o ícone fica com ✓ verde se a página for a publicada, e a página fica tapada por um aviso vermelho se não for.

3. À mão

Descarrega cada ficheiro desta página e compara a impressão digital SHA-256 com a publicada, por exemplo:

curl -s https://privada.recato.ai/privada.js | shasum -a 256

A página (index.html) traz as impressões digitais do privada.js e do estilo.css, e o browser recusa outros; o privada.js traz a do módulo da caixa-forte (privatemode.wasm) e recusa outro.

Recato private chat: how to check

In the private chat, what you write is encrypted on your phone or in your browser and only read inside a verified secure enclave. Recato's server only passes encrypted bytes along. Saved chats are encrypted with a key only you have.

All of this depends on the screen's code being the published one. In the app and in the extension, that code comes installed with them. On this page, it comes from Recato's server on every visit. So there are three ways to check it.

1. In the Android app

The private chat screen comes inside the app and only changes with a new version in the store. Its files are in the app under assets/privada/ and have the published fingerprints.

2. With the «Recato — Private chat» extension

In Chrome, Edge and Firefox, the private chat opens from the copy of the screen that comes inside the extension: the code does not come from the server. And if you open this page with the extension, it checks it: the icon shows a green ✓ if the page is the published one, and a red warning covers the page if it is not.

3. By hand

Download each file of this page and compare its SHA-256 fingerprint with the published one, for example:

curl -s https://privada.recato.ai/privada.js | shasum -a 256

The page (index.html) carries the fingerprints of privada.js and estilo.css, and the browser refuses others; privada.js carries the fingerprint of the enclave module (privatemode.wasm) and refuses another.
